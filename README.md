# Open Travel Platform

> Modern, reusable open-source starter for travel agencies, tour operators and booking products.

Open Travel Platform is being built from a clean repository history as a modular travel product starter. It is designed to run immediately in demo mode and later connect to external APIs or full-stack adapters without coupling the UI to a specific vendor.

## Status

**v0.1.0 — Foundation**

The first milestone establishes the application shell, domain model, demo adapter, environment contract, CI and open-source governance.

## Principles

- **Clean-room implementation** — original code and design created for this repository.
- **Demo-first** — clone, install and run without external infrastructure.
- **Adapter-based** — backend and third-party integrations sit behind explicit interfaces.
- **Secure defaults** — no production endpoints, secrets or credentials in source control.
- **Portable** — no dependency on one hosting provider, CMS, payment gateway or travel supplier.
- **Open source** — MIT licensed.

## Planned product areas

- Destination discovery
- Trips and travel packages
- Search and filtering
- Customer accounts
- Reservations
- Operator/admin workflows
- REST API adapters
- Optional provider/payment/CRM connectors
